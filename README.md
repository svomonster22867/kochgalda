# Учёт книг

Простая консольная программа на Python для учёта выданных книгл 
Сделаны две версии:
app_v1.py — выдача, просмотр, сброс, выход
app_v2.py — добавлена команда "вернуть книгу"

# Как запустить

Нужен Python в терминале в папке проекта

# Управление
1 — выдать книгу
2 — показать счётчик
3 — сбросить счётчик
4 — вернуть книгу (только v2)
0 — выход
Любой неверный ввод "-"
